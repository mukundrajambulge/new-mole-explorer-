# File

**Open** loads a coordinate object through canonical ingestion. **Import** opens the unified biological-data dialog. **Add Structure** appends another coordinate object without replacing existing objects. **Fetch** retrieves an official RCSB mmCIF by explicit PDB ID. **Save/Load Session** and **Export** preserve or emit the supported molecular project state through the existing lifecycle controls.

For biological data, choose Local file, Online ID, or Paste / text. The result opens in a typed sequence, map, trajectory, topology, or SMILES viewer. The left workspace keeps “No structure loaded” for these non-coordinate datasets because no molecular coordinate object has been fabricated; source name, format, status, and diagnostics are shown in the center viewer.
