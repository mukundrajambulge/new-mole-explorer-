# workers/prep environment

- `requirements.in`: exact pins of the direct dependencies (the tools the pipeline calls, plus scipy and
  gemmi, which Meeko imports without declaring).
- `requirements.lock.txt`: full transitive lock with sha256 hashes, generated by `pip-compile`.

Regenerate (WSL Ubuntu-24.04, repo root, needs network): `bash scripts/lock-prep.sh`. It rebuilds a fresh
`~/mole-lock` venv from the lock with `--require-hashes` and prints each tool's licence metadata; update
`native/third_party/TOOLS.md` from that output.

Install: `scripts/wsl-setup.sh` creates `~/mole-prep` with `pip install --require-hashes -r requirements.lock.txt`.
Tests: `node scripts/sprint/check.mjs --python` (lock completeness, pins vs TOOLS.md, Vina sha256, imports).
