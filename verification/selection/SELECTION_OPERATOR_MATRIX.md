## Status key

- `VERIFIED_WORKING`: automated or live evidence exists for the current implementation.
- `IMPLEMENTED_NOT_YET_VERIFIED`: legacy label; no current rows use this status. Code paths were promoted after the live matrix run.
- `BROKEN`: a reproduced failure exists and is not repaired.
- `MISSING_IMPLEMENTABLE`: legacy label; no current rows use this status.
- `MISSING_DEPENDENCY`: the required scientific or presentation dependency is absent.
- `UNKNOWN_PROPERTY`: the query names a field outside the declared canonical property namespace.
- `RESEARCH_REQUIRED`: the accepted grammar or semantics are not pinned tightly enough to implement safely.
- `ORACLE_PASS`: exact query form was executed successfully by the pinned PyMOL source.
- `ORACLE_EQUIVALENT`: the application alias was compared with a documented native PyMOL equivalent.
- `ORACLE_PENDING`: a pinned PyMOL oracle case is still required or the native equivalent grammar was deliberately not guessed.
- `INTENTIONALLY_UNSUPPORTED`: explicitly gated; no fake behavior is exposed.

The matrix is intentionally honest: a parser branch alone does not promote an operator to verified conformance.
