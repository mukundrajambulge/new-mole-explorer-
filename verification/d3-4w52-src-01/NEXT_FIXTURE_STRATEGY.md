# Next fixture strategy after D3-4W52-SRC-01

Input: D3-EXT-FIX-01 strategy escalation and the source outcome recorded here. This recommendation changes how candidate discovery is sequenced; it does not select a new ligand/receptor, broaden the scientific domain or authorize preparation.

## Avoid another serial rejection cycle

Use a bounded cohort workflow. Before deep coordinate analysis, assemble a small candidate cohort from a reproducible query and run a single source-first screen over every candidate in parallel stages. Require each candidate to have: an accessible primary construct/purification source; exact sample sequence or authoritative deposited construct mapping; explicit tag/cleavage and terminal evidence; ligand CCD identity; coordinate completeness; and a reachable validation report. Record “source not resolved” early and stop deep geometry work for that candidate until evidence improves. Then perform full ligand-shell, water, alternate-state and component audits only for the source-complete survivors.

The first reviewable deliverable should be a source-tractability matrix with source URLs, retrieved-file checksums, construct sequence coverage, tag/terminus status and a short inclusion/exclusion reason for the entire cohort. An independent structural-biology reviewer should verify the sequence/construct claims before expensive coordinate or scoring work. This lets the owner compare several source-ready options at once instead of investing in one promising candidate whose crucial methods source is unavailable.

## Gate sequence

1. Owner confirms fixture purpose and chooses the eligible experimental domain.
2. Search a bounded cohort using frozen database queries and exact CCD identities; retain raw query results and source artifacts.
3. Batch-screen source availability and exact construct/terminus provenance before ranking local geometry.
4. Obtain independent structural-biology review of the surviving construct records.
5. Run detailed geometry, ligand, alternate-state, water and component audit only for survivors.
6. Present one or more candidate dossiers for a separate preparation-authorization gate. Do not prepare, protonate, add hydrogens, generate PDBQT or score during discovery.

If the source-complete cohort is empty, return one cohort-level finding and ask the owner to choose among a revised bounded search, a formally designed purpose-built experimental micro-fixture, or an explicitly authorized domain change. Do not silently substitute synthetic coordinates or expand the scorer domain. This strategy is a recommendation for owner review; it is not a new search authorization.
