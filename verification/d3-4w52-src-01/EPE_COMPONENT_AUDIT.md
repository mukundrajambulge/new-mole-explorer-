# EPE component audit

4W52 contains one EPE component, the CCD name 4-(2-hydroxyethyl)-1-piperazine ethanesulfonic acid (HEPES), label asym C / author chain A / author residue 201. It has 15 deposited heavy atoms at occupancy 1.00. The minimum distance from any EPE heavy atom to BNZ is 12.445 Å (EPE C2 to BNZ C3). It is outside the local BNZ cavity and is not a covalent adduct or co-ligand at the selected BNZ site.

The source supports classifying EPE as a crystallization/buffer component for a future dry receptor state, not as an essential BNZ-site component. A future preparation authorization should state its omission explicitly and retain its source identity; this audit does not strip EPE from any prepared structure because none was made.
