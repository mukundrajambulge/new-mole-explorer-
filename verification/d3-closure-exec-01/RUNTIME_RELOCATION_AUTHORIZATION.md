**Scope:** D3-CLOSURE-EXEC-01 only. **Status:** owner authorization recorded from the 2026-10-04 runtime-unblock continuation.

This authorization changes only the execution platform. No unofficial signing, patched native binary, alternate chemistry engine, or unapproved RDKit release was used. The failed Windows runtime and its logs remain preserved in this evidence package.

Execution remains bounded to the already owner-approved, single-use 3DMX/BNZ development bootstrap. Linux relocation is not general production authorization, does not enable D4 search, and does not enable `DOCKING.RUN`.
