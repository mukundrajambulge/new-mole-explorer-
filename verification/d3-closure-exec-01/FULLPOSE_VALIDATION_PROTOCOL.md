# Full-pose validation protocol status

**Harness ready; fixture execution remains blocked before state binding.** The executable deterministic runner is in `tools/full_pose_compare.py`, `tools/full_pose_compare.cpp`, and `FULLPOSE_HARNESS.md`. It builds one scoring field from the frozen receptor projection, transforms copies of one frozen ligand coordinate set, and sends the same per-pose coordinates and state/profile digests through direct and interpolated scoring. Grid OOD and invalid samples fail closed without direct fallback.

The runner compiled under WSL2 Ubuntu 24.04.5 with GCC 13.3.0 and passed its five-pose `SYNTHETIC_CONTROL` smoke test. That control only checked orchestration and scorer consumption; its temporary output was discarded. It is not fixture evidence and did not populate the scientific result tables.

The 3DMX/BNZ run remains blocked because the frozen preparation profile does not resolve A/B alternatives at ASN68, ASP72, and ARG76. No eligible sealed states or pose inputs exist. The requested manifest classes are crystal, controlled translation, controlled rotation, combined transform, and grid phase, with an explicitly tagged cutoff-stress subset. Exact transforms and pose IDs must come from the frozen, fixture-bound validation manifest; none are invented here.

For an authorized sealed-state run, record per pose both direct and interpolated five-term raw values, weighted values, `E_inter`, term/total deltas, scorer torsion quantities, cutoff-stress classification, transformed-pose digest, and exact boundary/OOD disposition. The input bundle must bind the identical receptor/ligand/SearchRegion/profile digests to both paths. The normalized scoring projection is not a substitute for D2 state sealing; the runner verifies artifact byte hashes and embedded digest links but does not reseal D2 objects.

The current PHD-V2-13 `1e-10`/`1e-12` comparators are engineering/backend equivalence tolerances for specified comparisons. Current PHD-V2 acceptance amendments leave direct-versus-grid approximation error and ranking thresholds unapproved. A future completed run reports the measured distributions and evidence without converting those engineering tolerances into a scientific gate.
