# Full-pose validation protocol status

**Current status: fixture execution complete.** The v1.1 profile passed completeness validation, preparation replay and D2 sealing passed, and the six-pose SEALED_STATES direct/grid run completed. The original protocol text below describes the runner contract; current results are in fullpose/results/ and D3_CLOSURE_EXEC_01_REPORT.md. The executable deterministic runner is in `tools/full_pose_compare.py`, `tools/full_pose_compare.cpp`, and `FULLPOSE_HARNESS.md`. It builds one scoring field from the frozen receptor projection, transforms copies of one frozen ligand coordinate set, and sends the same per-pose coordinates and state/profile digests through direct and interpolated scoring. Grid OOD and invalid samples fail closed without direct fallback.

The runner compiled under WSL2 Ubuntu 24.04.5 with GCC 13.3.0 and passed its five-pose `SYNTHETIC_CONTROL` smoke test. That control only checked orchestration and scorer consumption; its temporary output was discarded. It is not fixture evidence and did not populate the scientific result tables.

That earlier blocker was resolved within this same closure package under the bounded owner continuation authorization. The six fixture-bound poses and exact transforms are recorded in VALIDATION_POSE_COHORT.json and the output manifests; no stochastic search was run.

For an authorized sealed-state run, record per pose both direct and interpolated five-term raw values, weighted values, `E_inter`, term/total deltas, scorer torsion quantities, cutoff-stress classification, transformed-pose digest, and exact boundary/OOD disposition. The input bundle must bind the identical receptor/ligand/SearchRegion/profile digests to both paths. The normalized scoring projection is not a substitute for D2 state sealing; the runner verifies artifact byte hashes and embedded digest links but does not reseal D2 objects.

The current PHD-V2-13 `1e-10`/`1e-12` comparators are engineering/backend equivalence tolerances for specified comparisons. Current PHD-V2 acceptance amendments leave direct-versus-grid approximation error and ranking thresholds unapproved. The completed run reports the measured distributions without converting engineering tolerances into a scientific gate. No approved direct-versus-grid threshold was identified; see the D3-FINAL-01 evidence-backed recommendation.
